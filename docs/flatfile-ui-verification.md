# Flat File UI Verification

The final sandbox layout shows a saved-dataset selector, a Flat File upload control, source controls, cost assumptions, and the paper-only execution state. Desktop keeps the controls within the main card and preserves a separate method-notes panel. Mobile collapses the form to one column; the saved dataset selector and upload control remain reachable without horizontal overflow. The UI continues to disclose that demo bars are illustrative and that Massive/provider data requires provenance and quality checks before trusting results.
